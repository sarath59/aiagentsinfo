Crux, from Marouane Gazouzi, writes the X post you did not sit down to write. It starts from a commit, a merged pull request, or a release on the repos you choose. The plugin for Claude Code and Codex can send a short note on what changed and who it is for, which a commit message usually skips. Pro leaves the posting click to you.

## Best for

An indie hacker who ships on GitHub and wants three drafts in their own voice, scored against their own posts, a few minutes after the work lands.

## Watch out for

Autopilot is the plan that can post, and it posts only what you schedule. It cannot reply, like, or follow. The $49 launch deal is Pro for life and does not include scheduling. When the 7-day trial ends without a paid plan, the account is read-only. Learnings claim nothing until a result beats a chance test on your own posts. Text from a private repo you watch goes out to a free model through OpenRouter so the draft can be written. Crux reads commit messages, pull-request text, and changed file names. It does not fetch the diff.

TrustMRR verifies Crux with a Stripe API key. On November 11, 2026 that page showed no active subscriptions, so there is no MRR figure to cite.
