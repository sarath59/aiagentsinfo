Bannerbear is a template API. You design the frame once. An HTTP call, a workflow, or an [agent](/glossary/agent) on the MCP server fills it and gets an image, a PDF, or a video back. Jon Yongfook is named as founder on the [about page](https://www.bannerbear.com/about/), dated from January 2020. Automate, at $49 a month, is the plan that includes the API and the MCP server. The trial is 30 API credits and does not ask for a card.

## Best for

A developer who needs the same branded frame at volume, and who wants Claude, ChatGPT, or Codex to run that frame from chat.

## Watch out for

API credits and AI credits are separate. A plain image is one API credit, times formats and scale. Face detection, background removal, and an AI background each add an AI credit on the layer that uses them. Animation is two API credits per second, rounded up. Burning subtitles is four tool credits because it transcribes as well as encodes. The trial can call the API, and the trial caps (one workspace, three templates of each kind) apply to API calls too. AI credits can be topped up. Running out refuses the request instead of billing you negative.
