1ClickWebsite.ai, from Bennett Black, is a site builder for agencies. You start a site, then a Website Agent edits the copy, the pages, the images, and the layout in chat. Every current plan includes an API and an MCP server, so ChatGPT, Claude, or Cursor can create and edit sites with the same credits. The homepage still describes the output as WordPress sites. The plans page also says you can export and host the site anywhere.

## Best for

An agency owner who sells client sites and wants the agent, the export, and the MCP server on the entry plan.

## Watch out for

Hosting is not in the $49. It is $10/month or $65/year for each site you leave on their host. New sites sit on a temporary preview address for 14 days. Credits do not roll over, including on annual plans. Lead-gen mini sites start on Professional. TrustMRR still lists an Expert plan at $197/month. The plans page says Expert is a legacy plan at $179/month and is no longer sold.

TrustMRR verifies revenue with a Stripe API key. Checked November 10, 2026: current MRR $14,165, all-time revenue $104,989, with 434 active subscriptions. TrustMRR last updated that page at 8:12 AM the same day.
