OpenTweet, from Branko, is a scheduler for X that an agent can drive. You write on a calendar, let the AI draft in a voice you train, or pipe RSS, GitHub, or Stripe events in through connectors. The site documents a REST API, a Claude Desktop extension, and an MCP server, so a coding agent can post without a separate X developer app.

## Best for

A founder who posts on one X account and wants the queue, the drafts, and the agent path on the same bill.

## Watch out for

The trial is the only free access. On the trial, link posts stop at 5 total and X search stops at 2 a day. Evergreen, X Articles, and DM sending wait until the paid plan. The priced caps on the table are X accounts. The site also documents cross-posting to Bluesky and LinkedIn, which is a separate surface from those X caps. TrustMRR's blurb still says plans start at $11.99 a month. The live pricing page starts at $19.99.

TrustMRR verifies revenue with a Paddle API key. Checked November 10, 2026: current MRR $4,553, all-time revenue $30,404, with 242 active subscriptions. TrustMRR last updated that page at 3:40 AM the same day.
