Cline is a coding [agent](/glossary/agent) you run yourself. Plan mode is where you agree the approach. Act mode is where it edits. You approve each step, or you turn on auto-approve. The same runtime is a desktop app, an IDE extension, a CLI, and an SDK. The license at [github.com/cline/cline](https://github.com/cline/cline), read November 12, 2026, is Apache-2.0. There is no Cline seat to buy for the open-source agent.

## Best for

A developer who wants the agent loop, MCP tools, and repo rules in a tool they can install, and who will pay Anthropic, OpenAI, or another provider directly.

## Watch out for

The bill is the model's bill. The pricing page says you can use the Cline provider instead of your own key, and it does not print that provider's rates. Enterprise is a sales link with no price on the page read November 12. Auto-approve removes the step check that Plan/Act is built around. `.clinerules` in the repo is how you pin standards. The homepage also describes coordinator agents that delegate to specialists, which is a second loop on top of Plan/Act, not a cheaper plan.
