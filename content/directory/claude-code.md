Claude Code is a [coding agent](/glossary/agent). The product page is the source for where it runs and which plan includes it. Anthropic Claude Code limits for Pro, Max, and Ultra are in the section below. The comparison of list prices with Codex is a separate article, [Claude Code vs Codex pricing](/blog/claude-code-vs-codex-pricing), not the name of this product.

## How is Claude Code different from Codex?

[Claude Code](https://claude.com/product/claude-code) is Anthropic’s coding agent. [Codex](/directory/codex) is OpenAI’s. Anthropic’s page was read again on November 7, 2026, and the notes below still match it. The Codex notes are what OpenAI’s page said on November 5, 2026. They are not a quality ranking.

Anthropic’s page says you steer Claude Code from the terminal, an IDE, Slack, or the web. The surface list is the terminal, the web, iOS, Android, GitHub, VS Code, JetBrains, and Slack. The editor line says the VS Code extension also covers [Cursor](/directory/cursor) and Devin Desktop. The page says it is available for macOS, Linux, and Windows. Its FAQ says the terminal version runs locally and asks before it changes files or runs commands. The same FAQ says you can use it with a Pro, Max, or Ultra plan, a Team or Enterprise plan, or a Claude Console account. The Team block on that page is $20 per seat per month when billed annually, for teams of 2 to 150.

OpenAI’s page says Codex is included with a ChatGPT plan, and that you use the same agent in ChatGPT, an editor, and the terminal. It also describes an IDE extension, cloud tasks that keep running after you close the laptop, and automatic pull-request review. The prices printed there are Plus at $20, Pro at $100, and Business at $20. Business is noted for two or more seats, billed annually.

## How does Claude Code vs Codex pricing compare?

On the pages checked November 5, 2026, both vendors list a $20 plan, and the rest of the ladder is not the same. This page’s pricing summary lists Claude Code Pro at $20 per month, Max at $100, and Ultra at $200, and says Claude Code is not on the Free plan. The Codex paragraph above lists Plus at $20, Pro at $100, and Business at $20 for two or more seats, billed annually. The [Codex listing](/directory/codex) records a different free-tier rule: Codex is included on Free and Go, with limits, and Codex Cloud is not. Those are list prices from the vendor pages, not a measure of how much work each plan includes. The full ladder, rechecked November 6, 2026, including Claude Team standard and premium seats and Codex Pro at $100, $200, and $500, is [Claude Code vs Codex pricing](/blog/claude-code-vs-codex-pricing). The software around either model is a [harness](/glossary/harness). The longer guide is [What is an AI agent harness?](/blog/what-is-an-ai-agent-harness). Plan limits move. Use the vendor page for a number you intend to rely on.

## What is Claude Duet?

[Claude Duet](https://claude.com/product/claude-duet) is not a Claude Code mode. Anthropic’s product page, read November 7, 2026, calls it a proactive agent you hand work to through messages. It works on its own computer in the cloud, using apps you connect, and it messages you when it is done or needs a decision. The same page says it is a standalone app for iOS and Android, and that on a computer you open it at claude.ai. It is a research preview on a waitlist for Claude Pro, Max, and Ultra subscribers in the United States. Team and Enterprise plans are not included yet. During that preview it shares the plan’s usage limits with the rest of Claude. The [announcement](https://claude.com/resources/articles/claude-duet) says the same about the plans and the shared limits.

Phone control of a Claude Code session is a different feature. Anthropic’s [mobile docs](https://code.claude.com/docs/en/mobile), read November 7, 2026, say the Claude app for iOS and Android is a client for Claude Code sessions, not a place where the code runs. [Remote Control](https://code.claude.com/docs/en/remote-control) connects that app, or claude.ai/code, to a session that is already running on your computer. The code stays on your machine, so the computer has to stay on. Claude Duet’s announcement says its virtual machine keeps working when your laptop is off. Those are two products.

## What are the Anthropic Claude Code limits?

On a Pro, Max, or Ultra plan, Claude Code draws from the same usage pool as the rest of Claude. Anthropic’s [help center article](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-max-or-ultra-plan), read November 7, 2026, says Pro and Max have a five-hour session limit and a weekly limit. Ultra has a weekly limit, and verified Ultra accounts do not have a five-hour session limit. The [pricing page](https://claude.com/pricing), read the same day, says Max is 5 times Pro usage every five hours and every week, and Ultra is 10 times Pro usage every week, with no five-hour limit for verified accounts. The page also says there is no fixed message count. The side-by-side with [Codex](/directory/codex) is [Claude Code vs Codex pricing](/blog/claude-code-vs-codex-pricing).

The [Claude Code changelog](https://code.claude.com/docs/en/changelog) for version 2.1.317, dated November 3, 2026, says that release added a check that asks before a web or shell tool call sends your account email address to the network. That line is the changelog note. This page does not have a separate incident report, and it does not describe versions before 2.1.317.
