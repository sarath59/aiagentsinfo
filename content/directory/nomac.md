NoMac is a Mac an [agent](/glossary/agent) can rent by the minute. The job it is for is Apple software: archive, sign, and simulator-test from a machine the agent boots itself. The page lists Claude, ChatGPT, Codex, and Cursor as clients, over [MCP](/glossary/model-context-protocol), a CLI, an API, or SSH. The published rate is $0.90 an hour.

## Best for

A coding agent that has to run Xcode and does not have a Mac sitting on a desk.

## Watch out for

This is a full admin session, not a locked permission [harness](/glossary/harness). The page says the machine has root, and it names Xcode 27, iOS 27, Homebrew, Node, Python, and CocoaPods as what is installed. Credit is prepaid and does not expire. There is no monthly plan to forget about, and there is also no public founder name on the site as of November 11, 2026. Enterprise pricing is a conversation, not a card.
