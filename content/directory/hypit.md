Hypit is a video [harness](/glossary/agent-harness) for an agent you already run. The homepage says an agent can edit footage, dialogue, B-roll, captions, and effects, anchored to words rather than to a timeline in seconds, and that Claude, Codex, or another agent can drive it. The open-source core is priced at $0. The install line on the homepage is `npx skills add hypit-ai/hypit -g`. Hosted credits start at Starter, $9.90 a month for 1,800 credits.

## Best for

A developer who wants a coding agent to reproduce a reference video as a workflow, then re-run that workflow with new words and new assets.

## Watch out for

Hosted use has three meters, not one. Video and images spend credits by the model. An agent turn holds 100 credits when it starts, then settles to the real cost. A cloud workspace keeps spending while Studio is open, including while you are idle, until you end the session. The $39.90 and $99.90 figures are the yearly cards, printed next to $49.90 and $129.90.
