## What is the GitHub Copilot price in November 2026?

On November 9, 2026, GitHub lists Copilot Free at $0, Pro at $10 a month, Pro+ at $39 a month, and Max at $100 a month.

[GitHub’s plans page](https://github.com/features/copilot/plans) prints those four stickers. [The billing docs](https://docs.github.com/en/copilot/concepts/billing-and-usage/individuals/billing), read the same day, say one AI credit is $0.01. Pro includes 1,500 credits a month (1,000 base and 500 flex). Pro+ includes 7,000 (3,900 base and 3,100 flex). Max includes 20,000 (10,000 base and 10,000 flex). Free includes 2,000 code completions a month and limited chat and agent use through auto model selection. Paid plans list completions as unlimited and not billed in credits. Unused credits do not carry over. The allowance resets at 00:00 UTC on the first of the month.

The same docs say that through November 30, 2026, paid plans get a 30 percent discount on model costs when using Copilot Fusion, and a 10 percent discount when using auto model selection. Organization and enterprise seat prices are on GitHub’s licence page. They are not repeated here.
