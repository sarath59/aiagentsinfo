Slashspace is Praneeth Pike’s desktop canvas for AI chats. You keep several threads on one board and jump between them, with your own API keys, a Claude or ChatGPT subscription, or Slashspace’s hosted models. The product used to be called Rabbit Holes AI. A lifetime purchase from that name carries over.

TrustMRR still lists the revenue under Rabbit Holes AI and verifies it with a Stripe API key. Checked November 9, 2026: current MRR $174, last 30 days $2,601, all-time revenue $131,971, with 19 active subscriptions.
