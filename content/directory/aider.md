Aider is a coding [agent](/glossary/agent) that lives in the terminal. It builds a map of the repo, edits the files, and makes a git commit you can diff. The license on [github.com/Aider-AI/aider](https://github.com/Aider-AI/aider), read November 11, 2026, is Apache-2.0. There is no Aider plan to buy.

## Best for

A developer who wants the agent in the shell, on a repo they already have, and who is fine paying Anthropic, OpenAI, DeepSeek, or a local model directly.

## Watch out for

The bill is the model's bill. The homepage examples, read the same day, still name Claude 3.7 Sonnet, DeepSeek R1, OpenAI o1, o3-mini, and GPT-4o. The same page says Aider can connect to almost any LLM, including a local one, so those names are examples, not a current model menu. Voice-to-code, image context, and a lint-and-test loop are listed as features. None of them adds an Aider fee.
