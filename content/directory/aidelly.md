Aidelly is Wilzer Jean-Baptiste’s social product for agencies that want an agent to do the posting. The homepage is explicit about the setup: an agent drafts and publishes, and the team approves. The site also labels MCP and an API on the product, so Claude, ChatGPT, or another assistant can run the account instead of a person clicking through every network.
