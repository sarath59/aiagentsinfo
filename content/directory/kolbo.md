Kolbo.AI, also written Kolbo AI and kolbo ai, is a creative workspace that keeps chat, images, video, music, voice, 3D, docs, and review inside one project. The homepage schema names Zohar Vanunu as founder and CEO. You do not bring model API keys to start. Kolbo holds those connections. People search kolbo ai pricing, kolbo ai login, kolbo ai app, and kolbo ai free because the product is a web app, a desktop app, and phone apps, and the free plan is real.

The homepage FAQ, read 2026-11-14, lists the production set it keeps current: chat models such as GPT, Claude, and Gemini; image models such as Midjourney, Flux, Ideogram, and Nano Banana; video models such as Kling, Hailuo, Seedance, Sora, and Veo; music through Suno; voice through ElevenLabs and DeepDub. Auto mode can pick a model. You can also send the same prompt to several models and compare. Visual DNA is how a character, product, or style is tagged so it carries across models, not only inside one locked model. Moodboards work the same way. Creative Director takes one concept and returns a set of scenes, about 2 to 8, writes a prompt per scene, runs the model you pick, and can stitch clips or send them to the editor.

## What you can run without leaving the project

The tool list on the homepage is the practical map. Chat includes multi-model chat, AI docs, presentations, custom agents, and Kobi on WhatsApp and Telegram. Images cover create, canvas, upscale, reframe, face swap, background removal, inpaint, skin enhance, and LoRA training. Video covers text to video, first and last frame, elements, video to video, lipsync from an image or a video, 4K upscale, reframe, extend, and dubbing. Audio covers music, a studio, text to speech, sound effects, transcription and subtitles, voice changer, dialogue fix, vocal separation, stems, and a trained voice model. 3D covers a world, image to 3D, multi-image to 3D, and text to 3D. Flow chains tools into a batch pipeline. Review collects timestamped notes on a cut. A stock library sits beside generation for photos, video, vectors, 3D, music, and sound effects, including licensed music.

Kolbo Studio is the desktop app for Mac and Windows. Plugins cover Premiere Pro, After Effects, and DaVinci Resolve. The FAQ says DaVinci's own rule requires a paid DaVinci license. Generated media can be dragged onto the timeline. The Premiere plugin also does Hebrew captions, reels from long footage, and podcast helpers. The product is RTL-native, with Hebrew, English, and Arabic named on the organization schema. There are iOS and Android apps so a project started on a phone stays in the same workspace.

## Agents, API, and teams

Kobi Code is a local agent. It runs on your computer, edits real files, and can drive Kolbo tools through MCP for Claude, ChatGPT, Gemini, and others. The homepage positions it for work on disk: timelines, folders, batch jobs, and code. Kolbo MCP is the other door: an agent you already use can call Kolbo's creative tools. A developer API exists, and the pricing-facts scope says developer USD wallet pricing is separate from personal web credits. There is no fixed exchange rate that turns a subscription credit into a dollar on that API.

Teams are not priced per seat. The FAQ says you pay for credits, share a project with no per-person fee, and organizations get one shared credit pool, a branded login, unlimited members, and a usage dashboard. Content protection is on by default. A stricter content-restricted mode can be turned on for a personal account or a whole organization, including a school or college that wants a modest workspace. That setting is an admin control, not a children's product.

## Best for

A creator or a small studio that is paying several model vendors separately and wants one credit pool, the same character across models, and a plugin path into Premiere or DaVinci.

## Watch out for

The number on the button during this promotion is not the renewal. Monthly first-period prices end 2026-11-15T21:59:59Z, and the base renewal is what the JSON lists as the catalog price before future changes. Existing subscribers keep the price they signed up at, so a new-checkout table is the wrong quote for an old account. Unlimited does not cover the API, MCP, or Kobi Code. Developer API dollars are a different wallet. Generation cost depends on model, mode, resolution, duration, and audio, and the pre-generation quote is the number that matters. Do not treat Kolbo credits as interchangeable with another product's credits.
