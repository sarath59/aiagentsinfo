**Tool use** (also called function calling) is how a model steps outside the text box. The [harness](/glossary/harness) decides which tools exist, how arguments are validated, and what the model is allowed to see of the result.

Without tools, you have dialogue. With tools and a loop, you have an [agent](/glossary/agent). A catalog lookup or a payment call is the same pattern in a store: see [product feed](/glossary/product-feed) and [agentic checkout](/glossary/agentic-checkout).
