A **harness** is the software around the model weights. It feeds the goal, exposes [tools](/glossary/tool-use), stores observations, retries, and stops. Two products can share a model and behave differently because the harness differs.

Designing that software is [harness engineering](/glossary/harness-engineering). Choosing the next step or agent is [orchestration](/glossary/orchestration). A check that allows, blocks, or pauses an action is a [guardrail](/glossary/guardrail). A test of one observable action is a [behavioral evaluation](/glossary/behavioral-evaluation). The cycle it runs is the [agent loop](/glossary/agent-loop). The long explainer of that cycle is [How do AI agents work?](/blog/how-do-ai-agents-work). The longer guide to the workshop itself is [What is an AI agent harness?](/blog/what-is-an-ai-agent-harness). How to test the workshop is [How do you evaluate an AI agent harness?](/blog/how-do-you-evaluate-an-ai-agent-harness). A sourced comparison of coding, open-source, and local runtimes is [Best AI agent harness](/best/ai-agent-harnesses). Nineteen framework release tags are [Best AI agent frameworks](/best/ai-agent-frameworks). Public scores are the [November 2026 agent harness benchmark](/reports/agent-harness-benchmark-november-2026). The short pointer is the [harness comparison tracker](/trackers/harnesses).
