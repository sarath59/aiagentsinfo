A **harness** is the software around the model weights. It feeds the goal, exposes [tools](/glossary/tool-use), stores observations, retries, and stops. Two products can share a model and behave differently because the harness differs.

Designing that software is [harness engineering](/glossary/harness-engineering). Choosing the next step or agent is [orchestration](/glossary/orchestration). A check that allows, blocks, or pauses an action is a [guardrail](/glossary/guardrail). A test of one observable action is a [behavioral evaluation](/glossary/behavioral-evaluation). The longer guide is [What is an AI agent harness?](/blog/what-is-an-ai-agent-harness). How to test the workshop is [How do you evaluate an AI agent harness?](/blog/how-do-you-evaluate-an-ai-agent-harness).
