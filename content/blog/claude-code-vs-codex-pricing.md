## Which costs less, Claude Code or Codex?

Codex costs less to start. On the pages checked November 6, 2026, [Codex](/directory/codex) is included with ChatGPT Free at $0 and with Go at $8 a month, and [Claude Code](/directory/claude-code) starts on Pro at $20 a month, or $17 a month when you pay $200 up front for the year.

After that, the individual monthly prices line up. Claude Pro and ChatGPT Plus are both $20 a month. Claude Max and the first Codex Pro tier are both $100. Claude Ultra and the middle Codex Pro tier are both $200. Codex Pro also lists a $500 tier, and the Claude individual pages checked here do not. Those are list prices. They are not a count of how much code each plan will write.

[Claude Code](https://claude.com/product/claude-code) is Anthropic’s coding agent. Codex is OpenAI’s. Each one is an [agent](/glossary/agent): a model plus the [harness](/glossary/harness) that runs tools, keeps a record, and stops. The longer account of that surrounding software is [What is an AI agent harness?](/blog/what-is-an-ai-agent-harness). [Claude](/directory/claude) is the chat product on the same Anthropic plans. [ChatGPT](/directory/chatgpt) is the plan Codex rides on.

Prices below exclude tax where the vendor says so. Anthropic says its prices can change. OpenAI’s pages describe the current cards and send you to a usage dashboard for the live limit. Use the vendor page for a number you intend to pay.

## What are the Anthropic Claude Code limits?

Anthropic Claude Code limits, on the pages checked November 6, 2026, are the plan’s limits. Claude Code is not a separate meter.

Pro has a five-hour session limit and a weekly limit. Both are shared with the rest of Claude. The pricing FAQ says there is no fixed message count. Max is 5 times Pro usage every five hours and every week. Ultra is 10 times Pro usage every week, and verified accounts have no five-hour limit. The tables above put those windows next to Codex. [Claude Code](/directory/claude-code) is the product note. [Codex](/directory/codex) is the other column.

This page does not have a separate price for a Claude Code subagent. The vendor pages checked for this comparison do not print one. A background task still draws on the same pool, or on API rates after the included allowance, which is the split in the sections above.

## What should you check before you pay?

1. Pick the surface first. Claude Code’s product page lists the terminal, the web, iOS, Android, GitHub, VS Code, JetBrains, and Slack, and it says the VS Code extension also covers Cursor and Devin Desktop. Codex’s docs list the CLI, the IDE, the desktop app, the web, and cloud tasks on the plans that include cloud.
2. Read the pool, not only the price. Claude Code and Claude chat draw from one pool. Codex, ChatGPT Work, and the other agent features named on the help page draw from a shared allowance when your plan uses one.
3. Treat message ranges as estimates. Anthropic says the mix of length, model, and features means there is no fixed message count. OpenAI says similar tasks can consume different amounts, and prompt length alone is a poor estimate.
4. Keep a receipt path for overage. Usage credits, a Console account, or an API key are how either product continues after the included allowance. Team monthly API credits are not that path for Claude Code.

## Frequently asked questions

### Which costs less, Claude Code or Codex?

Codex costs less to start. Free ChatGPT includes it, and Go is $8 a month. Claude Code starts at Pro, $20 a month or $17 a month on an annual bill. The $100 and $200 individual prices match. Codex Pro also lists $500.

### Is Claude Code on the free plan?

The [Claude pricing table](https://claude.com/pricing) marks Claude Code unavailable on Free and available on Pro, Max, and Ultra. Paid plans include it, and the product page adds Team, Enterprise, and Console.

### Does free ChatGPT include Codex?

Yes. The [Codex docs](https://learn.chatgpt.com/docs/pricing) list Free at $0, and the [help center](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan) includes Free and Go. Codex Cloud is not included on those two plans.

### What does the $20 plan include for a coding agent?

Claude Pro includes Claude Code in the same pool as the rest of Claude, with a five-hour limit and a weekly limit. ChatGPT Plus includes Codex on the web, in the CLI, in the IDE, and on iOS, plus cloud code review and Slack. Neither page promises a fixed number of tasks.

### Do Claude Max and Codex Pro cost the same?

At $100 and $200, yes. Codex Pro also offers $500, which is the tier with Ultrafast mode. Max is 5 times Pro usage on both the five-hour window and the week. The Codex docs say Pro plans have no five-hour limit.

### How much is a team seat?

Claude Team standard and ChatGPT Business are both $20 per person per month when billed annually, and both are $25 when billed monthly, for at least two people. Claude premium seats are $100 annually or $125 monthly. Claude Enterprise, in the pricing FAQ, is $20 per seat per month plus API-rate usage, billed annually.

### Can I pay API rates instead of a subscription?

Yes. Console bills Claude Code at standard API rates. An OpenAI API key bills Codex at API rates in the CLI, SDK, or IDE, without the cloud integrations. Paid subscriptions can also buy credits after the included allowance runs out.

### What are the Anthropic Claude Code limits?

They are the plan’s limits, not a separate Claude Code meter. On the November 6, 2026 check, Pro has a five-hour session limit and a weekly limit, shared with the rest of Claude. Max is 5 times Pro usage on both windows. Ultra is 10 times Pro usage every week, and verified accounts have no five-hour limit. The pages checked here do not print a separate price for a background subagent. The [Claude Code listing](/directory/claude-code) has the same plan names, and [Codex](/directory/codex) is the other product.
